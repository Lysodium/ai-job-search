# Using AI Job Search in Claude Cowork

No terminal, no Git, no coding. If you can install an app and attach a file, you can use this.

## What you need

- The **Claude desktop app** with **Cowork** (a paid Claude plan).
- About 15 minutes for the first setup. Your current CV (PDF or Word) or a LinkedIn profile PDF makes it faster.

## Install (one time)

1. **Download the plugin file:** open [`cowork/ai-job-search.plugin`](cowork/ai-job-search.plugin) on GitHub and click the **Download raw file** button (the arrow icon at the top right of the file view).
2. **Open Cowork** in the Claude desktop app and start a new task.
3. **Drag the downloaded `ai-job-search.plugin` file into the message box** and send: *"Install this plugin."*
4. A plugin card appears. Click **Install** (or **Accept**).

## First run

In a new Cowork task, say:

> **Set up my job search.**

Claude will:

1. Ask where to keep your job-search folder (for example *Documents*). Approve the folder-access prompt.
2. Create an `ai-job-search` folder there with everything it needs.
3. Interview you about your experience, skills and what you're looking for - or read it from the CV/LinkedIn file you give it - and save your profile.

That's it. From now on, just say what you want.

## Everyday use

| Say | What happens |
|---|---|
| "Find me new jobs" | Searches job boards for postings that match your profile |
| "Rank my jobs" | Scores what was found and gives you a shortlist |
| "Apply to this job: *paste link or text*" | Checks the fit first, then writes a tailored CV and cover letter as PDFs |
| "Fill out the application for *Company*" | Fills the online form in your browser and **stops before Submit** - you review and click Submit yourself |
| "Prepare me for my interview at *Company*" | Builds a prep pack and can run a mock interview |
| "I got an interview with *Company*" / "*Company* rejected me" | Updates your tracker |
| "Check my email for application updates" | Reads Gmail and proposes tracker updates (needs the Gmail connector) |
| "Push my jobs to Notion" | Publishes your shortlist to Notion (needs the Notion connector) |
| "Show my job dashboard" | Opens your application tracker |
| "What should I learn next?" | Finds skill gaps across your target jobs and makes a learning plan |
| "Find me new jobs every weekday morning" | Sets up a Cowork scheduled task |

Your files appear in the `ai-job-search` folder: CVs in `cv/<company>/`, cover letters in `cover_letters/<company>/`, and your tracker in `job_search_tracker.csv`.

## Optional extras

- **Gmail / Notion:** turn on those connectors in Cowork's settings to use the email-sync and Notion features.
- **Filling applications in Chrome:** install the *Claude in Chrome* extension so Claude can use the browser where you're already logged in to job sites. Without it, Claude uses Cowork's built-in browser.

## Privacy

- Everything stays in your job-search folder on your computer. Nothing is uploaded or published unless you ask.
- Claude never submits an application, never solves CAPTCHAs or verification steps, and never fills in passwords, ID numbers, salary or demographic answers on its own.

## Troubleshooting

- **"Your job-search folder isn't connected."** Start the task from the Cowork desktop app and add your `ai-job-search` folder (the **Add folder** button), or just say *"Set up my job search"* again and point Claude at it.
- **PDFs couldn't be built.** Claude needs LaTeX to make PDFs. It installs what it can by itself; if your computer blocks that, Claude will tell you and leave the editable `.tex` files in your folder.
- **Already use this repo with Claude Code?** Nothing changes for you. Install the plugin and connect your existing folder - Cowork reads the same profile and files.
